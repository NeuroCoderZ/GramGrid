# 2026-11-14 00:43 MSK — GramGrid

2026-11-14 00:43 MSK — Экспериментальный вычислительный проект NeuroCoderZ для потребительских NPU. Цель — исполнять нейронные операции и модели на нейронных процессорах, соединяя устройства через независимый транспорт. CPU управляет процессами, сетью и проверкой результатов; CPU/GPU-инференс не является запасным вычислительным путём.

## 2026-11-14 00:43 MSK — Что уже работает

2026-11-14 00:43 MSK — Реальный AMD XDNA через XRT; целочисленные матричные ядра; резидентные веса; двоичный конверт GG02 с проверкой границ и CRC; маршрутизатор с проверками согласия, ревизии, ресурсов и бюджета участия. Два логических этапа на одном физическом NPU передают активации и состояние; результаты сравниваются с независимым эталоном. Это проверка операторов и протокола, не распределённый запуск полной LLM.

2026-11-14 00:43 MSK — Публичный срез содержит NPU-ядро и тестовые инструменты. Старые браузерные вычислительные эксперименты, личные журналы, история сессий, окружения, двоичные сборки и веса не входят в этот срез. Исходная рабочая история сохранена отдельно.

## 2026-11-14 00:43 MSK — Первый модельный эксперимент

2026-11-14 00:43 MSK — Выбран Qwen/Qwen3.5-0.8B. Для имеющегося XDNA2 есть пакет FastFlowLM/Qwen3.5-0.8B-NPU2 и тег qwen3.5:0.8b. На этой машине запуск выполняется через Lemonade с рецептом flm. GGUF Q4_K_M — формат хранения весов, а не гарантия исполнения на любом NPU; FLM NPU2 использует подготовленный пакет model.q4nx. Поддержка Qualcomm и Apple ещё не подтверждена физическими испытаниями.

2026-11-14 00:43 MSK — Локальный тест использует отдельную регистрацию модели и ограниченный контекст. Скрипт scripts/npu_llm_pilot.py проверяет NPU-рецепт и непустой ответ; он не нарезает модель на сетевые слои и не обещает перенос состояния FLM между устройствами.

## 2026-11-14 00:43 MSK — Проверка без вычислительного NPU

2026-11-14 00:43 MSK — На обычном хосте можно проверять протокол и маршрутизатор командой cargo test -p gramgrid-proto -p gramgrid-scheduler --lib --tests. Это структурные тесты на CPU, не инференс модели. Rust-зависимости при первом запуске должны быть доступны через Cargo; дальнейшие повторы можно выполнять с --offline.

## 2026-11-14 00:43 MSK — Реальный NPU-прогон

2026-11-14 00:43 MSK — Предварительные условия: Linux, совместимый AMD XDNA2, работающий XRT, Rust/Cargo, C++20 и существующее Python-окружение с NumPy и mlir-aie/Peano. Драйверы и службы скрипты проекта не устанавливают и не переключают автоматически. Для матричного ядра нужен xclbinutil в PATH либо локальный toolchains/xrt-utils/usr/bin; сторонние инструменты сохраняют собственные лицензии.

2026-11-14 00:43 MSK — Последовательность: запустить .venv/bin/python native/xdna/build_matmul.py; собрать g++ -std=c++20 -O2 -Wall -Wextra -Werror -fPIC -shared native/xdna/adapter.cpp -lxrt_coreutil -o native/xdna/build/libgramgrid_xdna_v2.so; затем bash scripts/build_mesh.sh. Эти команды требуют настроенного NPU-окружения и не заменяют его установку.

2026-11-14 02:11 MSK — Теперь есть отдельный ModelQuery-узел: cargo build -p gramgrid-node --example model_query, затем python3 scripts/test_model_query_node.py. Через loopback GG02 проходит настоящий запрос к полному NPU-профилю Qwen3.5-0.8B; повтор не запускает модель снова, изменённые вход/сессия/ревизия отклоняются. Этот сервис не использует маршрутизацию тензорных слоёв, не переносит KV и не является распределённым Transformer. Без явного --consent пример не стартует.

2026-11-14 03:02 MSK — Журнал ModelQuery включается явно: target/debug/examples/model_query --consent --state-dir .state/model-query. Он сохраняет сессию, исходный запрос и окончательный ответ в приватных файлах; после нового процесса сохранённый ответ возвращается без NPU-генерации. Проверка: python3 scripts/test_model_query_restart.py. Незавершённая запись не выдаётся за результат и не запускается повторно автоматически: исход предыдущей генерации может быть неизвестен. Требуется Linux и Rust не ниже 1.89 для штатной файловой блокировки. Пример без --state-dir сохраняет прежний режим кэша в памяти.

2026-11-14 00:43 MSK — Для модельного теста нужен отдельный работающий Lemonade с flm:npu. Не выгружайте чужие модели и не меняйте общую конфигурацию ради проверки. Команды регистрации и запуска, реальные результаты и бюджет памяти сохраняются в docs/PILOT.md. Веса загружаются отдельно в хранилище службы и не публикуются в Git.

## 2026-11-14 00:43 MSK — Транспорт и границы

2026-11-14 00:43 MSK — Протокол вычислений не зависит от Telegram или BitChat. Первый транспортный эксперимент планируется в локальной Wi-Fi-сети без выхода в интернет. BLE рассматривается для обнаружения и коротких управляющих сообщений, не как испытанный канал передачи весов. Интеграции BitChat, мобильного NPU, публичной P2P-сети и выплат пока нет; подробности и источники — docs/TRANSPORT.md.

2026-11-14 00:43 MSK — CRC обнаруживает ошибки передачи, но не удостоверяет честность узла. Открытый NPU не становится доверенным от наличия шифрования канала. Пока нет двух физических узлов, не заявляется ускорение распределённой модели, энергопотребление смартфона или надёжность публичной сети.
